# 08 공통 UI

> 여러 화면이 함께 쓰는 컴포넌트와 전역 스타일을 정리합니다. 화면별 구현은 09 문서를 봅니다.
> 파일은 모두 `src/components`에 있고, 컴포넌트마다 같은 이름의 `.module.css`를 함께 둡니다.

---

## 8.1. 전역 스타일 — `src/styles/global.css`

| 변수 | 값 | 쓰임 |
|---|---|---|
| `--color-primary` | `#111111` | 기본 검정 (글자·테두리·버튼 배경) |
| `--color-text` | `#111111` | 본문 글자 |
| `--color-muted` | `#666666` | 보조 설명, 비활성 글자 |
| `--color-bg` | `#ffffff` | 배경 |
| `--color-bg-sub` | `#f5f5f5` | 옅은 배경 (사진 자리, 요약 카드) |
| `--color-border` | `#e0e0e0` | 테두리·구분선 |
| `--color-like` | `#ed4956` | 흑백 디자인의 예외 색 (좋아요 하트, 장바구니 "재고가 없습니다.") |
| `--header-height` | `68px` | 위에 붙는 헤더 높이 (그 아래 붙는 요소의 기준) |

그 밖에 `container` 클래스(가로 폭 1100px, 좌우 여백 16px), 기본 글꼴, 링크·이미지 초기화를 전역으로 둔다.

## 8.2. 틀 컴포넌트

### Layout

모든 화면을 감싸는 틀이다. `Header` → `StorageNotice` → 화면 내용(`Outlet`) → `RestockPopup` → `Footer` 순서로 그린다.

| props | 기본값 | 역할 |
|---|---|---|
| `transparentHeader` | `false` | 홈에서 표지 사진 위에 헤더를 겹칠지 여부 |
| `restockPopup` | `true` | 재입고 알림 팝업을 띄울지 여부 (관리자 화면은 `false`) |

### Header

로고, ADMIN 버튼, 메뉴(HOME · CLOTHES · LISTS · ORDERS), 장바구니 아이콘을 담는다.

- 모든 화면에서 위에 붙어 따라오며(스티키), 배경은 반투명 + 흐림 처리라 내용이 비쳐 지나간다.
- 현재 화면의 메뉴는 `NavLink`의 활성 표시로 구분한다.
- 장바구니 아이콘에는 담긴 **수량의 합**을 숫자로 띄운다(0이면 표시하지 않는다, F-15).

### Footer

로고, 메뉴(HOME · CLOTHES · LISTS · ORDERS · CART), 안내 문구와 저작권 표시를 담는다.

- 메뉴는 헤더와 같은 화면으로 이어지며, 헤더에서 아이콘으로 둔 장바구니는 푸터에서 CART 글자로 둔다.
- 안내 문구로 실제 결제와 배송이 없는 수업용 모의 쇼핑몰임을 밝힌다.

## 8.3. 안내 컴포넌트

### StorageNotice — F-14

저장된 데이터를 읽지 못했을 때 헤더 아래에 검은 안내 줄을 띄운다.

- 어떤 데이터가 문제인지 이름으로 알려 준다(장바구니·주문 내역·좋아요 목록·의류 데이터·재입고 알림).
- **초기화** 버튼 → 확인 창 → 확인했을 때만 그 데이터를 지우고 기본값으로 시작한다.
- 안내가 떠 있는 동안 저장이 필요한 동작은 막힌다.

### RestockPopup — F-29

신청한 사이즈가 재입고되면 화면 오른쪽 아래에 뜨는 알림이다.

- 재입고 일시와 사이트를 연 시각 중 **늦은 시각에서 5초 뒤**에 뜬다.
- 여러 건이면 한 팝업에 모아 보여 주고, 각 줄에 사진·상품명·사이즈와 **보러 가기**가 있다.
- 한 번 띄운 신청은 '표시함'으로 저장해 다시 띄우지 않는다. 관리자 화면에서는 띄우지 않는다.

## 8.4. 목록·상품 컴포넌트

### ProductCard

목록에서 쓰는 상품 카드다. 사진(3:4로 잘라 맞춤), 브랜드, 상품명(한 줄 말줄임), 가격을 보여 주고 사진 오른쪽 위에 좋아요 버튼을 겹친다.

> 링크 안에 버튼을 넣을 수 없어서, 카드 링크와 좋아요 버튼을 나란히 두고 버튼만 사진 위에 겹쳐 놓았다.

### PriceTag — F-26

가격 표시를 한 곳에서 처리한다. 할인율이 0이면 가격만, 0보다 크면 **할인율 · 할인 가격 · 할인 전 가격(취소선)** 을 보여 준다.

| props | 값 | 쓰임 |
|---|---|---|
| `product` | 의류 | `price`, `discountRate`를 읽는다 |
| `size` | `card`(기본) / `detail` | 목록 카드용, 상세 화면용 크기 |

### LikeButton — F-16

좋아요 하트 버튼이다. 누르면 등록·해제되고, 좋아요한 상태는 빨간 하트로 채운다.

| props | 값 | 쓰임 |
|---|---|---|
| `productId` | 의류 번호 | 좋아요 대상 |
| `variant` | `card`(기본) / `detail` | 사진 위 원형 버튼 / 상세 화면의 네모 버튼 |

### Pagination — F-19

이전 · 페이지 번호 · 다음 버튼을 보여 준다. 첫·마지막 페이지에서는 이전·다음이 눌리지 않는다.

| props | 역할 |
|---|---|
| `currentPage` | 현재 페이지 번호 |
| `totalPages` | 전체 페이지 수 |
| `onPageChange` | 페이지를 눌렀을 때 |

### Breadcrumb

`HOME › MEN › 상의 › 티셔츠`처럼 현재 위치를 보여 준다. `items` 배열(`{ label, to }`)을 받아 마지막 항목만 링크 없이 표시한다.

## 8.5. 탐색 컴포넌트 (의류 목록)

### CategoryMenu — F-03·F-21

목록 화면 왼쪽 사이드바다. 위에서부터 **전체 / 초기화**, **브랜드**, **계절**, **대분류 › 중분류 › 세부 항목** 순서로 둔다.

- 브랜드·계절은 같은 모양의 접이식 칸(`OptionSection`)으로 만들고, 항목마다 의류 수를 함께 보여 준다.
- 중분류는 ▾로 접고 펼친다. 고른 항목은 검정 굵은 글씨와 밑줄로 표시한다.
- **초기화**는 브랜드·계절·분류·검색어·정렬을 모두 처음 상태로 되돌린다(F-22).

### SearchBox — F-02·F-20

성별 탭 오른쪽 끝의 돋보기다.

- 돋보기를 누르면 입력창이 옆으로 펼쳐지고, 다시 누르면 들어간다. 검색은 Enter로 한다.
- 입력창에 커서가 있으면 **최근 검색어**가 아래로 펼쳐진다(최대 10개, 개별 삭제·전체 삭제).
- 검색어는 주소의 `q`로 넘기고, 최근 검색어는 `ootd_recent_searches`에 저장한다.

### SortMenu — F-17

검색 옆의 햄버거 버튼이다. 누르면 **등록순 · 최신순 · 가격순 · 할인율순**이 펼쳐지고, 고른 기준에 ✓가 붙는다. 바깥을 누르거나 Esc를 누르면 닫힌다. CLOTHES 화면에서 아무것도 고르지 않으면 '무작위'로 표시한다.

### ColumnMenu (관리자 목록)

표의 **칸 제목 글자 자체**를 누르면 펼쳐지는 드롭다운이다. 등록일·가격·사이즈별 재고의 정렬과 상태 고르기에 쓴다. 기본값이 아닐 때만 제목 아래에 고른 값을 작게 표시한다.

## 8.6. 공통 규칙

- 버튼·입력칸의 기본 모양은 각 CSS Module에서 지우고, 흑백 테두리로 다시 만든다.
- 눌리지 않는 버튼은 회색(`--color-border`)으로 보여 주고 커서를 바꾸지 않는다.
- 드롭다운·팝업은 **바깥 클릭**과 **Esc**로 닫는다.
- 움직임을 줄이도록 설정한 사용자(`prefers-reduced-motion`)에게는 흐르는 띠·팝업 애니메이션을 멈춘다.
- 사진에는 의미가 없으면 `alt=""`를 주고, 아이콘 버튼에는 `aria-label`로 무엇을 하는 버튼인지 적는다.
