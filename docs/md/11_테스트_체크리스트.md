# 11 테스트 체크리스트

> 화면을 고친 뒤 이 목록으로 확인합니다. 통과하면 `[x]`로 바꿉니다.
> 기능 번호는 02 기능 명세서, 화면 번호는 03 화면 정의 목록서를 따릅니다.

**준비**: `npm run dev` (http://localhost:5175) → 브라우저 개발자 도구에서 `localStorage.clear()`로 저장 데이터를 비우고 시작합니다.

**2026-09-21 점검 결과**: 개발 서버(5175)에서 11.1~11.8을, 빌드 미리보기(4173)에서 11.9를 확인했고 **84개 항목 모두 통과**했습니다.
점검하며 만든 장바구니·주문·좋아요·재입고 알림·테스트 상품은 모두 지웠습니다.

## 11.1. 공통 (F-14·F-15)

- [x] 헤더 메뉴 HOME · CLOTHES · LISTS · ORDERS와 장바구니 아이콘이 모든 화면에 보인다
- [x] 현재 보고 있는 화면의 메뉴가 구분되어 보인다
- [x] 장바구니 숫자가 **수량의 합**이다 (2개 + 3개 → 5)
- [x] 장바구니가 비면 숫자가 보이지 않는다
- [x] 정의되지 않은 주소(`/abc`)로 들어가면 '페이지를 찾을 수 없습니다'가 나온다
- [x] 새로고침해도 장바구니·주문 내역·좋아요·재입고 알림이 남아 있다
- [x] `localStorage.setItem('ootd_cart', '{깨진 값')` 후 새로고침하면 안내 줄이 나오고, 담기·수량 변경이 막힌다
- [x] 안내 줄의 초기화 → 확인 창에서 **취소**하면 저장된 값이 그대로 남는다
- [x] 확인하면 그 데이터만 지워지고 다른 데이터(주문 내역 등)는 남는다

## 11.2. 의류 목록 (F-01·F-02·F-03·F-17·F-19·F-20·F-21·F-22)

- [x] CLOTHES에서 전체 의류가 나오고, 새로 들어올 때마다 순서가 섞인다
- [x] CLOTHES는 페이지 번호가 없고 모든 의류가 한 화면에 나온다
- [x] MEN·WOMEN·UNISEX 페이지는 한 페이지 12개(4×3)로 나뉜다
- [x] 돋보기 → 검색창 → Enter로 검색되고, 결과 개수가 나온다
- [x] 검색 결과가 없으면 '검색 결과가 없습니다.'와 조건 초기화 버튼이 나온다
- [x] 검색창에 커서를 두면 최근 검색어가 나오고, 10개를 넘으면 오래된 것이 사라진다
- [x] 최근 검색어를 누르면 다시 검색되고, ×와 전체 삭제가 동작한다
- [x] 사이드바에서 브랜드·계절·분류를 고르면 결과가 함께 걸러진다
- [x] 계절 '여름'을 고르면 사계절 의류는 나오지 않는다
- [x] 정렬 메뉴의 등록순·최신순·가격순·할인율순이 각각 맞게 정렬된다
- [x] 조건 하나를 바꿔도 나머지 조건이 유지되고 페이지만 1로 돌아간다
- [x] 초기화를 누르면 검색어·브랜드·계절·분류·정렬이 모두 풀린다

## 11.3. 의류 상세 (F-04·F-05·F-06·F-16·F-26·F-27·F-28)

- [x] 사진·브랜드·상품명·가격·설명·의류 종류·계절·성별·사이즈가 나온다
- [x] 할인 중인 의류는 '할인율 · 할인 가격 · 할인 전 가격(취소선)'으로 보인다
- [x] 없는 번호(`/products/9999`)로 들어가면 '의류를 찾을 수 없습니다'가 나온다
- [x] 사이즈를 고르지 않고 담으면 '사이즈를 선택하세요.'가 나온다
- [x] 수량 입력에 0, 1.5, abc, 한도 초과를 넣으면 직전 값으로 되돌아가고 범위를 안내한다
- [x] 총 금액이 판매 가격 × 수량으로 바뀐다
- [x] 담으면 '장바구니에 담았습니다.'와 장바구니 보기 링크가 나오고 헤더 숫자가 늘어난다
- [x] 같은 사이즈를 또 담으면 수량이 합쳐지고, 다른 사이즈는 따로 담긴다
- [x] 재고 1~3개 사이즈에 '재고 부족(N개 남음)', 0개에 '재고 없음'이 보인다
- [x] 재고 없음 사이즈는 고를 수 없고 아래에 재입고 알림 버튼이 있다
- [x] 모든 사이즈가 0이면 '품절'이 뜨고 담기 버튼이 잠긴다
- [x] 재고보다 많이 담으려 하면 추가 가능 수량을 안내한다
- [x] 하트를 누르면 빨갛게 바뀌고 다시 누르면 풀린다
- [x] 다른 의류로 이동하면 사이즈는 선택 안 함, 수량은 1이다

## 11.4. 장바구니 (F-07·F-08·F-09·F-27)

- [x] 사진·브랜드·상품명·사이즈·수량·금액이 나오고 합계가 맞다
- [x] 배송비가 0원으로 표시된다
- [x] −/+로 수량이 바뀌고 1에서 −, 재고 한도에서 +가 잠긴다
- [x] 더 담을 수 없으면 수량 버튼 아래에 빨간 '재고가 없습니다.'가 나온다
- [x] 담은 수량이 재고보다 많으면 '재고 부족(남은 수량 N개)'이 뜨고 주문이 막힌다
- [x] 삭제하면 항목이 사라지고 합계·헤더 숫자가 갱신된다
- [x] 마지막 항목을 지우면 '장바구니가 비어 있습니다.'가 나온다
- [x] 관리자 화면에서 의류를 지우면 그 항목이 '구매 불가'로 바뀌고 주문이 막힌다

## 11.5. 주문 (F-10·F-11·F-12·F-13·F-18)

- [x] 주문하기 → 주문서에 장바구니 전체와 최종 금액이 나온다
- [x] 배송 정보를 비우고 주문하면 항목별로 '…을 입력하세요.'가 나온다
- [x] 공백만 입력해도 오류로 처리되고, 입력한 다른 값은 남는다
- [x] 주문 완료 후 주문 번호·일시·받는 분·결제 금액이 나온다
- [x] 주문한 항목이 장바구니에서 사라지고 재고가 줄어든다
- [x] 뒤로 가기를 해도 주문서로 돌아가지 않는다
- [x] 주문 내역에 최근 주문부터 나오고 배송비·최종 금액이 보인다
- [x] 주문 취소 → 확인 창에서 취소하면 아무것도 바뀌지 않는다
- [x] 확인하면 상태가 '주문 취소'로 바뀌고 취소 일시가 보이며 재고가 되돌아온다
- [x] 취소된 주문에는 취소 버튼이 없고 금액은 그대로다
- [x] 저장을 일부러 실패시키면(개발자 도구에서 `localStorage.setItem` 오류) 주문·장바구니·재고가 모두 그대로다

## 11.6. 좋아요·목록 (F-16, S-11·S-12)

- [x] 목록 카드와 상세의 하트 상태가 서로 같다
- [x] LISTS에서 좋아요 목록·재입고 알림 목록으로 갈 수 있다
- [x] 좋아요 목록에 등록한 순서대로 나오고, 하트를 풀면 목록에서 빠진다
- [x] 좋아요가 없으면 '좋아요한 의류가 없습니다.'가 나온다
- [x] 관리자 화면에서 좋아요한 의류를 지우면 '정보 없음'과 해제 버튼만 남는다

## 11.7. 재입고 알림 (F-28·F-29)

- [x] 재고 없음 사이즈에서 재입고 알림을 신청하면 '신청 완료'로 바뀐다
- [x] 재입고 알림 목록에 의류·사이즈·신청 일시와 '재입고 기다리는 중'이 나온다
- [x] 신청 취소가 동작한다
- [x] 관리자에서 그 사이즈 재고를 채우면, 사용자 화면에서 **5초 뒤** 팝업이 뜬다
- [x] 관리자 화면에서는 팝업이 뜨지 않는다
- [x] 팝업의 '보러 가기'로 상세로 이동하고, 닫기로 닫힌다
- [x] 새로고침해도 이미 알린 신청은 다시 뜨지 않는다
- [x] 여러 건이 재입고되면 한 팝업에 모여 나온다

## 11.8. 관리자 (F-23·F-24·F-25·F-26)

- [x] 헤더의 ADMIN 버튼으로 관리자 화면에 들어간다
- [x] 성별 탭으로 목록이 걸러지고 개수가 맞다
- [x] 상품명 돋보기로 검색 바가 열리고, 열고 닫아도 표가 밀리지 않는다
- [x] 등록일·가격·재고 정렬과 상태 고르기가 각각 맞게 동작한다
- [x] 조건에 맞는 결과가 없어도 칸 제목 줄이 남아 조건을 되돌릴 수 있다
- [x] 상품 추가: 빈 값·잘못된 값(가격, 할인율 91)을 넣으면 항목별로 안내한다
- [x] 저장하면 목록 맨 위에 새 상품이 생기고 사용자 화면에도 나온다
- [x] 새 상품의 번호가 이전 최대 번호 + 1이고, 삭제 후 등록해도 번호가 다시 쓰이지 않는다
- [x] 수정 화면에 기존 값이 그대로 채워지고, 저장하면 번호·등록일이 유지된다
- [x] 재고 −10 / − / + / +10 버튼이 동작하고 0 아래로 내려가지 않는다
- [x] 할인율을 넣으면 판매 가격 미리 보기가 맞고, 목록·상세에도 할인 가격이 보인다
- [x] 삭제는 확인 창을 거치고, 지운 의류는 목록·검색에서 사라진다
