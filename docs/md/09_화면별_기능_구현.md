# 09 화면별 기능 구현

> 화면마다 어떤 파일이 어떤 기능을 담당하는지 정리합니다. 데이터 연결은 10 문서, 공통 컴포넌트는 08 문서를 봅니다.
> 화면 번호는 03 화면 정의 목록서, 기능 번호는 02 기능 명세서를 따릅니다.

---

## 9.2. S-01 홈

- 표지(히어로)는 자리에 고정된 채 스크롤에 따라 흐려지고, 사진만 조금 확대된다. 확대를 사진에만 준 이유는 화면 밖으로 넘쳐 가로 스크롤이 생기지 않게 하기 위해서다.
- MEN·WOMEN·UNISEX 배너는 `/products?gender=...`로 이동한다.
- 의류 종류가 흐르는 띠는 같은 문구를 이어 붙여 끊김 없이 움직인다.
- Today's OOTD 카드는 사진 위에 착용한 옷 정보를 겹쳐 보여 주고, 연결된 의류 이름을 누르면 상세로 간다. 카드의 하트는 게시물 하트이며 상품 좋아요(F-16)와는 다르다.

## 9.3. S-02 의류 목록

| 기능 | 구현 방법 |
|---|---|
| F-01 목록 | 성별·조건으로 거른 의류를 `ProductCard`로 표시 |
| F-02 검색 | `SearchBox`에서 Enter → 주소의 `q` 변경. 상품명·브랜드·분류를 대소문자 구분 없이 찾는다 |
| F-03·F-21 필터 | `CategoryMenu`의 브랜드·계절·분류. 성별 페이지에서만 제공한다 |
| F-17 정렬 | `SortMenu`에서 고른 값을 주소의 `sort`로 넘긴다 |
| F-19 페이지 | 한 페이지 12개. 조건이 바뀌면 1페이지로 돌아간다 |
| F-20 최근 검색어 | `SearchBox`가 저장·표시·삭제까지 담당 |
| F-22 조건 결합 | 조건 하나를 바꿔도 나머지는 주소에 그대로 남긴다. 결과가 없으면 안내와 **조건 초기화** 버튼 |

- 화면 구분: 주소에 `gender`가 있으면 성별 페이지(사이드바 + 페이지네이션), 없으면 CLOTHES(성별 탭 + 무작위 배치, 페이지 나누지 않음).
- CLOTHES의 무작위 순서는 화면에 들어올 때 한 번 섞고, 탭·검색으로 다시 그릴 때는 그대로 둔다.
- 적용 순서는 **브랜드·계절·분류 → 검색어 → 정렬 → 페이지 나누기**다.

## 9.4. S-03 의류 상세

- 주소의 의류 번호로 의류를 찾고, 없으면 '의류를 찾을 수 없습니다'와 목록 이동을 보여 준다(F-04).
- 가격은 `PriceTag`로 표시하고 바로 아래에 상품 설명을 둔다. 해시태그(#대분류 #중분류 #세부 항목)는 그 조건의 목록으로 이동한다.
- 사이즈 버튼에 재고 상태를 함께 표시한다. 재고 없음 사이즈는 고를 수 없고, 그 아래에 **재입고 알림** 버튼이 생긴다(F-27·F-28).
- 구매 수량은 −/+ 버튼과 직접 입력을 모두 제공하고, Enter 또는 입력칸을 벗어날 때 검사한다. 잘못된 값은 직전 수량으로 되돌리고 범위를 안내한다(F-05).
- 수량 한도는 99와 재고 중 작은 값이며, 장바구니에 이미 담은 수량까지 합쳐 검사한다(F-06·F-27).
- 다른 의류로 이동하면 사이즈는 선택 안 함, 수량은 1로 돌아간다.

## 9.5. S-04 장바구니

- 줄마다 사진·브랜드·상품명·사이즈·수량·금액·삭제를 보여 준다(F-07).
- 수량은 −/+ 버튼으로 바꾸고 1~99 범위와 재고 한도를 지킨다(F-08·F-27).
- 더 담을 수 없으면 수량 버튼 아래에 빨간 "재고가 없습니다."를 표시한다.
- 삭제된 의류·없어진 사이즈는 **구매 불가**로 표시하고 삭제만 허용한다.
- 오른쪽 요약에 총 상품금액·배송비(0원)·총 결제금액을 보여 준다. 구매 불가나 재고 초과 항목이 있으면 주문하기 버튼을 잠근다.

## 9.6. S-05 주문서 · S-06 주문 완료

- 장바구니 전체를 주문 대상으로 보여 준다. 비어 있거나 구매 불가 항목이 있으면 장바구니로 돌아가게 안내한다(F-10).
- 배송 정보(수령인 이름·연락처·주소)는 빈 값만 검사하고 항목별로 안내한다. 연락처 형식은 검사하지 않는다(F-11).
- 주문 완료를 누르면 재고를 다시 확인하고, 주문 내역·장바구니·재고를 **한 번에 저장**한다. 실패하면 아무것도 바뀌지 않는다(F-12).
- 저장에 성공하면 주문 완료 화면으로 이동한다. 같은 주문을 다시 저장하지 않도록 제출 중에는 버튼을 잠그고, 이동할 때 현재 기록을 바꿔 뒤로 가기로 주문서에 돌아오지 않게 한다.
- 주문 완료 화면은 주소의 주문 번호로 저장된 주문을 찾아 번호·일시·받는 분·결제 금액을 보여 준다.

## 9.7. S-07 주문 내역

- 최근 주문부터 카드로 보여 주고, 카드마다 주문 번호·일시·상태·주문 의류·배송비·최종 금액을 표시한다(F-13).
- 사진은 주문에 저장하지 않으므로 의류 번호로 현재 의류에서 찾아 표시한다. 삭제된 의류는 빈 칸으로 둔다.
- 상태가 **주문 완료**인 주문에만 취소 버튼을 두고, 확인 창에서 확인해야 취소한다. 취소하면 상태·취소 일시를 저장하고 재고를 되돌린다(F-18).

## 9.8. S-08 좋아요 목록 · S-11 LISTS · S-12 재입고 알림 목록

- LISTS(S-11)는 두 목록으로 가는 카드를 보여 주고, 카드 아래 미리 보기에서 등록한 의류를 한 번에 세 개씩 `‹` `›`로 넘겨 본다. 자리가 남으면 로고를 연하게 넣은 빈 카드로 채워 두 카드의 높이를 맞춘다.
- 좋아요 목록(S-08)은 등록 순서대로 목록과 같은 카드로 보여 주고, 하트를 누르면 바로 빠진다. 삭제된 의류는 '정보 없음'과 해제 버튼만 둔다.
- 재입고 알림 목록(S-12)은 신청한 의류·사이즈·신청 일시와 상태(재입고 기다리는 중 / 재입고됨 / 알림 받음)를 보여 주고, 알림을 받지 않은 신청만 취소할 수 있다.

## 9.9. S-09 관리자

### 목록 화면

- 성별 탭(ALL·MEN·WOMEN·UNISEX)과 표(사진·상품명·등록일·가격·사이즈별 재고·상태·관리)로 보여 준다.
- 칸 제목에서 조건을 고른다: 상품명은 돋보기로 검색 바를 열고, 등록일·가격·재고는 정렬, 상태는 판매중·재고 부족·품절로 거른다. 정렬은 한 번에 한 칸만 적용한다.
- 상태는 재고로 판단한다(모두 0이면 품절, 1~3개가 있으면 재고 부족, 그 밖에는 판매중).
- 관리 버튼은 조회(상세 이동)·수정·삭제이고, 삭제는 확인 창을 거친다(F-24).
- 결과가 없어도 표의 제목 줄은 남겨 두어 조건을 다시 바꿀 수 있게 한다.

### 등록·수정 화면

- 왼쪽에 상품명·설명·브랜드·성별·계절·분류, 오른쪽에 사이즈별 재고·가격·할인율·사진을 둔다.
- 분류는 성별 → 대분류 → 중분류 → 세부 항목 순서로 이어서 고른다. 성별을 바꾸면 분류 선택을 비운다.
- 사이즈는 필요한 것만 체크하고, 체크한 사이즈에만 재고 칸이 열린다. 재고는 −10 / − / 입력 / + / +10으로 조절한다(F-25).
- 할인율을 넣으면 그 아래에 판매 가격을 미리 보여 준다(F-26).
- 사진은 준비된 사진 중에서 고른다(업로드 없음).
- 저장하면 새 상품은 저장해 둔 다음 번호와 오늘 날짜로 등록되고(F-23), 수정은 번호와 등록일을 그대로 둔다(F-24). 재고가 0에서 1 이상이 되면 재입고 일시를 기록한다.

## 9.10. 공통 처리

| 상황 | 처리 |
|---|---|
| 정의되지 않은 주소 | '페이지를 찾을 수 없습니다' 표시 (S-10) |
| 저장 실패 | 화면 상태를 바꾸지 않고 실패를 안내한다 |
| 저장 데이터 손상 | 헤더 아래 안내 줄, 저장이 필요한 동작 차단, 확인 후에만 초기화 (F-14) |
| 재입고 알림 | 사용자 화면 공통 팝업, 관리자 화면 제외 (F-29) |
